#  Cineplus — Cinema Ticket Booking

Cineplus es una aplicación web de reserva de entradas de cine desarrollada como proyecto práctico.

El objetivo es simular un proceso simple de reserva, permitiendo al usuario seleccionar una película, elegir un horario, indicar la cantidad de entradas y confirmar la reserva.

##  Demo

🔗 [Ver Cineplus en Vercel](https://cineplus-app-two.vercel.app/)

##  Características

-  Visualización de películas disponibles
-  Selección de película
-  Selección de horario
-  Selección de cantidad de entradas
-  Confirmación de reserva
-  Resumen de la reserva
-  Mensaje de confirmación exitosa
-  Diseño responsive

##  Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Vercel
- Git & GitHub
